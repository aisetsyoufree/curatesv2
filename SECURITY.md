# Security policy

CU-Rates.org V2 is an educational, evidence-backed directory. It is pre-launch: nothing is
deployed, no live collection is enabled, and no personal data is collected.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository
(Security tab, "Report a vulnerability"). Do not open a public issue for a vulnerability and
do not include personal data, account numbers, or other sensitive financial records in any
report.

## Scope and expectations

- In scope: the code in this repository, its dependencies, and its collection and
  publication controls (see `MASTER.md` section 5).
- Reports are triaged on a best-effort basis; there is no bug bounty.
- The project never bypasses authentication, CAPTCHAs, rate limits, or bot protection when
  collecting public data; a report that the collector does so is treated as a defect.
