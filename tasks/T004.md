# T004 — Initialize repository quality baseline

## Objective

Create the authoritative active implementation clone outside iCloud and establish a minimal,
reproducible Python quality baseline before feature code begins.

## Dependencies

T001 through T003 are done.

## Non-goals

No domain schema, scraper, database, website feature, or deployment work.

## Allowed changes

Repository packaging and tool configuration, one minimal importable package, smoke
tests, developer commands, and this task packet. The integrator owns `PROJECT.md`.

## Acceptance criteria

- Create a full clone, not `git worktree add`, at `~/Code/cu-rates.org-v2`; its `.git`
  directory, checkout, `.venv`, caches, databases, and generated files are outside
  iCloud. The iCloud copy becomes a frozen planning mirror after accepted commits are
  transferred, and all integration occurs in the outside clone.
- Python 3.12 is pinned in `.python-version`, bounded by `requires-python`, managed
  with `uv`, and locked in a committed `uv.lock`.
- Ruff, mypy in strict mode, and pytest run through one committed `scripts/check`
  command; the individual commands remain directly runnable.
- A fresh environment can reproduce the checks without globally installed packages.
- Generated and sensitive runtime files are ignored.

## Data, migration, and publication impact

None. This task creates tooling and a minimal package only.

## Required verification

- `uv sync --locked`
- `scripts/check`

`scripts/check` must run `uv run ruff check .`, `uv run mypy src tests`, and
`uv run pytest` and fail if any component fails.

Record versions, commands, and results in the handoff.
