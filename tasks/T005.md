# T005 — Inventory reusable V1 assets

## Objective

Create an evidence-based inventory of reusable knowledge from the V1 repository
without copying its architecture or trusting its financial data.

## Dependencies

T001 through T003 are done. May run in parallel with T004.

## Non-goals

No code migration, live scraping, normalization, or declaration that a V1 rate is
current.

## Allowed changes

One inventory report under `research/`, optional machine-readable inventory data,
and this task packet. Do not modify V1.

## Acceptance criteria

- Catalog source URLs, known vendors/platforms, fixtures, parsers, content, tests,
  deployment knowledge, and visual assets.
- Label every item `candidate_reuse`, `reference_only`, `obsolete`, or `unknown` with
  a reason and V1 path or commit reference.
- Treat all V1 rates, institution statuses, and URLs as unverified leads.
- Identify license, secret, privacy, and provenance risks.
- Recommend only the smallest set worth revalidating in V2.

## Required verification

- Confirm the V1 worktree remains unchanged with `git -C ../cu-rates.org status --short`.
- Validate every cited V1 path exists.
- Record inventory counts by disposition in the handoff.
